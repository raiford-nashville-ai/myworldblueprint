# Interface translations

## Purpose

Hold future Hugo translation dictionaries for shared Studio interface text.

## Rules

- Add translations only as part of an authorized localization task.
- Use stable message keys and preserve accessible labels, interpolation fields, and pluralization semantics.
- Keep interface translations separate from authored world content.
- Do not partially migrate strings or duplicate translation ownership between templates and JavaScript without a coherent plan.
- This folder is currently reserved; do not add placeholder dictionaries merely to fill it.
