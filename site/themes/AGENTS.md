# Optional themes

## Purpose

Reserve space for reusable Hugo themes if a future task explicitly requires them. The current Studio uses project-owned layouts and assets.

## Rules

- Do not install, vendor, or switch themes without approval.
- Do not duplicate the current application here to manufacture a theme boundary.
- If a theme is introduced, review license, provenance, version pinning, and overrides before adoption.
- Keep third-party files distinct from project-owned sources; do not patch dependency internals silently.
