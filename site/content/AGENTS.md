# Authored content

## Purpose

Hold future publishable Hugo pages and approved canonical semantic nodes. No world content is populated yet.

## Rules

- Do not seed content or migrate blueprints here without an approved content/schema task.
- One canonical graph page represents one semantic node with a stable node.id.
- Never derive semantic identity from filenames, URLs, titles, or folder paths.
- Keep publishing metadata separate from root node: metadata.
- Validate ontology classifications, relationship predicates, and target IDs before accepting graph changes.
- Do not treat simulated browser fixtures as canonical content.
- AGENTS.md is authoring guidance, not a content page; keep it excluded from Hugo's content mount.
