# Studio markup

## Purpose

Express the approved Tool navigation, clean creative workspace, guidance, and Blueprint View.

## Ownership

- sidebar.html: brand, Tool navigation mount, and future-Tool indicators.
- topbar.html: location, mobile navigation control, and theme toggle.
- workspace.html: intention input, action, status, and output placement.
- writing-tips.html: progressively disclosed worldbuilding guidance.
- creative-direction.html: content-generation choices, not UI configuration.
- blueprint-view.html: response container, export, provenance, and submitted-brief disclosure.

## Rules

- Preserve existing IDs and accessibility relationships used by browser modules.
- Keep guidance progressively disclosed and the central canvas visually quiet.
- Do not add decorative frames or configuration controls without a design request.
- Dynamic entities and response sections are rendered by assets/js/blueprint.js; avoid duplicate rendering ownership.
- Keep simulation and noncanonical provenance visible.
